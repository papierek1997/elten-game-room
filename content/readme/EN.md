Power Games is a collection of games for ELTEN users. You can meet friends at a table, join an open game, watch others play or take on bots in games that support them.

ELTEN reads out cards, boards, scores and events, while sounds help you follow the action. All games share the same tables, chat, history and help, so much of the interface will already feel familiar when you try another title.

## Getting started

Stereo headphones are recommended for audio games, where the direction of sound matters.

1. Open Power Games from ELTEN's program list.
2. Select “Create a new table”, choose a game and set its variant. In the same form you can decide whether the table should be private.
3. Invite other players or add bots if the game supports them. For a team game, choose and confirm the teams.
4. Select “Start game”. If you need help, press F1 for the available shortcuts or Ctrl+F1 to read the rules.

You do not have to create your own table. “Join a table” lets you choose a game and browse existing tables. You can also use an invitation or the widget on ELTEN's main screen.
When choosing a game to create or join a table, you will hear a short description after its name.
In Duck Racing's challenge settings, each item's name and checked state are followed by a short explanation of the challenge.
Opening Power Games again in the same copy of ELTEN takes you back to its existing window instead of starting a second independent instance.

On startup, the program may offer to download a newer version. Declining does not stop you from opening it, but it is worth making sure everyone has an up-to-date version before playing together. You can read about changes in “What's new”.
This is a read-only document with a heading for each version. H moves to the next heading and Shift+H to the previous one. Escape closes the document.

## What you can play

Power Games currently includes 35 games:

- Card games: 3-5-8, 99, 1000 miles, Biblios, Bridge, Makao, Spades, Poker, Rummy, Thousand, UNO, War and Scientific War.
- Board and strategy games: Ludo, Four in a Row, Tic Tac Toe, Mancala, Monopoly, Reversi, Battleships, Chess, Checkers and Duck Racing.
- Dice and dominoes: Cat, head, tail, Dominos, Farkle, Mexican Train and Yahtzee.
- Words and knowledge: Krowa, Categories, Quiz Party, Scrabble and Taboo.
- Audio action games: Axel Pong and Audio Ball.

Many games have several variants. The choices, player counts, bot support and additional settings depend on the game. Detailed rules, scoring and controls are described in the program's “Game rules” section.

Bridge has two variants: social rubber bridge, and duplicate bridge, which lasts a set number of boards and compares each board with a reference score in IMPs or matchpoints. With a single table, the reference is an estimate based on high card points, not other pairs' results. On your turn, choose a call from the list in the game field with the arrow keys and Enter, or press B. Declarer also plays dummy's cards: Tab moves to dummy's list and D reads dummy's hand. L reads the auction, K the contract and P the previous trick.

In Taboo, you need to communicate with the other players. You can use an ELTEN conference, another messaging app or play in person.

## Tables and playing together

### Public and private tables

A public table can be found in the table list. A private table does not appear there and is intended for invited players. A table's description includes the game, host, key variant details and game status.

In the table list and widget, you can find out more before joining:

- Ctrl+R reads the selected table's variant and settings.
- Ctrl+W lists its players and spectators.

### Inviting and watching

At a table, Ctrl+I opens invitations to online users, while Ctrl+Shift+I lets you choose someone from your contacts. You can accept invitations through an ELTEN notification, the context menu or Ctrl+J. The last shortcut works throughout Power Games, including the widget.

In games that allow spectators, you can follow a game without taking a player's seat. This is useful both for cheering people on and for learning the rules. Axel Pong spectators can also choose their listening perspective.
Ctrl+Shift+O lets you ask to play or spectate in the next game, where that choice is available.
This shortcut changes your own role. To change someone else's role, the host uses the Users list's context menu; the action names the selected person.

On the user list, Enter opens ELTEN's usual user menu. From there you can, for example, send a message, add someone to your contacts or call them.

### The host and managing bots and teams

The host prepares the table, starts games and manages the participants. In games with bots, the host can add a computer opponent with Ctrl+O. The bot receives a name and appears on the same list as the other players.

On the user list, the host also has two commands for the selected person:

- Ctrl+M transfers the host role to that person.
- Ctrl+Shift+R replaces a player with a present spectator or a bot, if the game and its current stage allow it.

When the host leaves, another participant can take over the table. In supported games, the program replaces a departing player with a bot so the others can continue.

Teams are selected in a separate window. You can randomise them, change a person's team with Enter or move people with Shift+Up and Shift+Down. Confirming teams returns you to the table; the game only begins when you select “Start game”. You do not have to set up teams again for the next game with the same participants.

Nor do you have to close the table just to play again. The host can end the current game with Ctrl+Q and change the next game's settings with Ctrl+X between games. These commands are also in the table menu.

Many games let you set a turn time limit and a delay for bot moves. The bot delay controls the pace; it does not select a difficulty level. The consequence of running out of time depends on the game's rules and is explained in its help, rather than applying one penalty to every title.

“Leave” and “Close the table for everyone” are different actions. The first means that you leave; the second closes the entire table and is a host command. Simply opening help, a menu or a leave confirmation does not pause play.

## Controls and help

Tab and Shift+Tab move between parts of the window, such as the game area, chat, history and user list. Arrow keys navigate lists or the board; how you make a move depends on the game.

Type a message in the Chat field and press Enter to send it. Each message can contain up to 2000 characters, both before and during a game.

You do not need to learn every shortcut at once:

- F1 shows help for your current location and the actions available there.
- Ctrl+F1 opens the selected game's rules, including its controls.
- Ctrl+R reminds you of your table's variant and settings.
- The context menu provides table-related actions.
- Ctrl+F4 reads connection latency, distinguishing HTTP from an available Communications or P2P connection.

You can read the rules before creating a table. They have chapters and a table of contents linking to each section. Game shortcuts appear in a separate list, with one item per shortcut.
The game list in the rules library includes a short description of each game.
In the rules text, H and Shift+H move between headings, K and Shift+K between links, and Enter on a contents link takes you to the chapter.

Some games also have personal settings under Ctrl+P, available in the table menu. These include Axel Pong, Audio Ball and Krowa. They control your own experience and are separate from the shared variant chosen by the host.

## The widget and quick table creation

The Power Games widget on ELTEN's main screen lets you browse tables without opening the program's main menu first. You can select a table, check its settings or participants and accept an invitation.
Ctrl+N goes straight to the game picker for a new table. R refreshes the list manually. The widget also refreshes when you enter it and every five seconds while you are using it.
Ctrl+O reads a short description of the game at the selected table. You can also choose “Game description” from the widget's context menu.

In Settings → Widget, you can enable the widget, choose which games it shows and restrict the list to tables created by your contacts.

### Your own table creation shortcuts

If you often play with the same settings, save them under one of 30 shortcuts: Ctrl+1 through Ctrl+0, Alt+1 through Alt+0 or Shift+1 through Shift+0.

1. Open Settings → Widget.
2. Tab to the table creation shortcuts list.
3. Select an entry and press Enter. You can also press the shortcut itself to jump straight to it in the list.
4. Choose a game, configure the table and confirm the assignment.

From then on, pressing the shortcut in the widget creates a table with the saved settings. It does not start the game automatically. The assignment is saved immediately, even if you later close the settings window with “Cancel”. Pressing Enter on the entry again lets you change it. You can remove an unwanted assignment through that list's menu.

The widget context menu shows command shortcuts. Assigned presets appear under their configuration names, alongside their shortcuts; unassigned presets are not shown in this menu.

## Notifications

In Settings → Notification settings, choose the games whose new public tables you want to hear about. For example, you can follow just Thousand and Categories, without notices about other games. Optionally, you can restrict these notifications to tables created by your contacts.

Separately, choose whether to show invitations from everyone, only contacts or nobody. Invitations and new table notifications have different sounds. Their descriptions include brief information about the game and its main settings; Ctrl+R gives you the full table settings.

In Settings → Lobby announcements, you separately choose which announcements are read while you are in the program's main window.

## Sounds and playing in the background

You can adjust the volume without leaving the game:

- F2 — quieter.
- F3 — louder.
- Shift+F2 — previous sound group.
- Shift+F3 — next sound group.

Choose all sounds together or separate groups: game sounds, people joining and leaving the table, chat, and invitations and notifications. The same levels are available in Settings → Sounds.

Moving to messages, a conference or another ELTEN window does not pause the game. This matters particularly in action games and when a turn time limit is enabled.

In Settings → General, you can separately choose:

- whether table announcements are spoken outside the table window;
- whether to play your turn signal;
- whether switching to another window should mute all games, only audio games or no games.

Game sounds are not muted by default. Muting them in the background does not replace the separate turn signal setting, nor does it silence chat, invitations or people joining and leaving. Background settings apply both to other parts of ELTEN and to switching to another program.

## Languages

Power Games has its own interface language selection in Settings → General. English, Polish, Czech, Spanish and Russian are available. This does not change the language of ELTEN itself. Restart ELTEN to apply the choice throughout Power Games, including the widget.

The optional “Known languages” list provides fallback translations. If text is missing in the main language, the program can use one of the selected languages and ultimately English.

You can choose the language of questions, cards or a dictionary in games that offer this setting. A new table defaults to its creator's interface language, or English if matching content is unavailable. Your saved settings take precedence. Joining a table or resuming a saved game does not change its language.

## Saved games and history

### Stop now and finish later

In games that support saving, the host can use Ctrl+S to save the game and close the table. The save belongs to the host's account and is stored on the server, so it can also be resumed on another computer.

Use “Saved games” in the main menu to resume. Restoring a save creates a table where you can gather the participants again and continue playing. Not every game can be saved, and not every moment is suitable: the command depends on the game and its current stage.

Once the game resumes, its save is removed from your account. Creating the table and waiting for players does not remove it yet. To stop again, save your current progress with Ctrl+S.

### Revisit a conversation or an earlier move

Table history includes game events, chat and changes at the table. You can read it as ordinary text or use shortcuts:

- Ctrl+Comma — previous entry in the selected category.
- Ctrl+Period — next entry in the selected category.
- Ctrl+Shift+Comma — previous category.
- Ctrl+Shift+Period — next category.
- Ctrl+Home — first entry in the category.
- Ctrl+End — last entry in the category.

Categories let you separate chat from game events or read everything together. The comma and period shortcuts also work while you type a message. In an editable field, Ctrl+Home and Ctrl+End retain their usual text navigation.

Ctrl+Shift+S saves the available table history to a TXT file in a folder you choose. You can use it to keep a conversation or a record of play. This is a text export, not a save you can later resume, and it does not close the table. Remember that the file may contain other participants' messages before sharing it.

## Leaderboards and statistics

“Leaderboards” collects results from games that support them. Krowa offers, among other things, a daily leaderboard and Word Tower results.

“Statistics” shows activity in Power Games, including games started and completed, broken down by game and by playing with people, with bots or alone. You can choose a period, such as the last seven days or all recorded time.

In Power Games' main menu, Ctrl+W opens the overview of people currently at tables, with table and participant counts. This differs from its use in the table list, where it reads the participants at one selected table.

## Features you might miss

### Sorting cards and finding a playable move

In card games that support shared hand sorting:

- Shift+C sorts cards by suit or colour.
- Shift+H sorts cards by rank or value.
- Shift+M restores the order in which you received them.

Using a sorting shortcut again reverses the order.

In supported games, Z and Shift+Z move to the next or previous playable card or tile. If there is just one unambiguous play, the shortcut may make the move immediately where the game permits it. It is therefore not always just a browsing command. This assistance is disabled in some fast UNO variants. F1 in the game area explains the exact behaviour.

### Your own way of reading the board

In Ludo, Ctrl+C switches descriptions between nicknames and colours, while C tells you who plays each colour. In Chess and Checkers, Ctrl+Shift+H rotates the board view; in Checkers, Ctrl+H switches between numbered squares and chess-style coordinates. These choices are remembered locally for future tables and do not change anyone else's view.

### Sound tutorials and move previews

Audio Ball's rules include an audio tutorial where you can listen to the sounds before playing. Ctrl+P also lets you choose an alternative sound pack from Audiodisc. Axel Pong has its own local settings under the same shortcut.

In Scrabble, other participants can see letters being placed and removed before the word is confirmed. Ctrl+P turns local announcements of those changes on or off. They are off by default; you do not need to enable them for everyone at the table.

### Connections in audio games

When creating an Axel Pong or Audio Ball table, you can optionally enable “Full P2P”: direct connections between participants where their networks allow it. The option is off by default. Enabling it reveals the P2P participant limit, which defaults to eight. ELTEN can still use a relay server when a direct connection is unavailable. Ctrl+F4 distinguishes the connections being measured.

## Tournaments

A tournament brings several games together into one competition. Power Games arranges the matches, records results and determines who plays whom next. You can join someone else's tournament or organise your own, for individual players or fixed pairs.

### Finding tournaments and getting back to yours

Choose “Tournaments” in the lobby. Select an event with the arrow keys and press Enter to open its action list. Tab moves between the list, its filter and the other controls. The filter lets you show:

- current tournaments, including those still accepting entries;
- “My tournaments”: current events you have joined or are organising;
- completed tournaments, so you can look up their results.

Current tournaments put the ones you have joined first, followed by those you can join, then all the others.

An abandoned tournament disappears after 14 days without activity before it starts, or 30 days without progress once it has started. Registrations and organiser changes renew that period before the start; match results renew it afterwards. Simply viewing a tournament does not. A future registration opening or start date is respected, so the tournament will not disappear before then. Completed tournaments keep their results.

Each entry includes the game, participant count and tournament status. These shortcuts are also available:

- Ctrl+N — create a tournament.
- Ctrl+R — refresh the tournament list.
- Ctrl+Shift+T — open your current tournaments from the lobby or widget. If there is only one, its action list opens straight away.
- Ctrl+J — open the usual invitation list, which also includes tournament match invitations.

F1 explains the controls in the current window; Escape goes back. Closing a window does not withdraw you from a tournament.

### Tournament actions

Opening a tournament takes you straight to its actions. Choose one with the arrow keys and press Enter. The heading gives the tournament's name and status.

- “Matches” — choose a fixture to play or look up the result of a completed match.
- “Results” — tournament standings, including earlier phases.
- “Participants” — the people registered for the tournament.
- “Tournament rules” — the organiser's description, game settings, competition format, qualification rules and dates.
- “Manage tournament” — the organiser's controls. Other participants do not have this option.

Joining, withdrawing and choosing a partner are offered when those actions are available.

### Signing up and choosing a partner

Choose “Join tournament” to register. If the option is unavailable, check the status in the heading: registration may not have opened, may have closed, or the tournament may be full. If you are already registered, you do not need to join again. Before the tournament starts, you can withdraw with “Leave tournament”.

In a fixed-pair tournament, both players register individually first. Then:

1. Open “My partner” and choose another participant.
2. Ask that player to choose you on the same screen.
3. Once you have chosen each other, the pair is confirmed. The partner screen also tells you when you are still waiting for agreement.

Before the start, you can change or clear your choice. The organiser can assign partners too. Team fixtures cannot be prepared while some participants are still without partners. You keep the same partner throughout the tournament and share a team result.

You receive a notification when the tournament starts, even while browsing tournaments. Its sound follows your usual notification settings.

### Starting a match

You do not need to create a separate table or find one among the public games.

1. Open your tournament — you can use Ctrl+Shift+T from the lobby or widget — and choose “Matches”.
2. Select one of your unplayed matches and press Enter or Ctrl+G, or choose “Play” from its context menu. Confirm to open a table with the tournament settings and invite the other participants.
3. The others accept the ordinary table invitation through an ELTEN notification or Ctrl+J and join the table directly.
4. Once everyone is at the table, its host chooses “Start game”. From there, use the game's usual controls.

Any participant in that match can open its table; the organiser need not be present. The table's user list shows who has joined.

Anyone not assigned to that match automatically joins as a spectator, even before the game starts. This includes tournament participants who are scheduled to play a different match.

An invitation lasts five minutes. Declining it, letting it expire or leaving the table does not count as a loss or withdraw you from the tournament. Choose “Play” again to return to the existing table and invite anyone still missing.

Leave any other game before entering the match. You cannot take a seat at two tables at once. If an empty table was closed before play began, you can open the match again. A game that has already started is not automatically replaced with a new one; resume it through “Saved games”.

### Matches, results and interrupted games

“Matches” opens on the current tournament phase. The first item gives its name, such as “Quarterfinals”, and the number of completed matches. Your unfinished matches come next, followed by everyone else's unfinished matches, then all completed matches. Everyone sees the full list.

Press Tab to select a phase. You can browse earlier phases here. If you are viewing the current phase, the list follows the next one when it begins. Refreshing keeps the selected match as long as it is still visible.

Enter on a completed match tells you it has already been played. Open its result with Ctrl+W or “Match result” in the context menu. The same menu shows the available actions and their shortcuts: Ctrl+G to play, Ctrl+F to award a forfeit, and Ctrl+Shift+F to cancel a started match and award a forfeit. The last two actions are for the organiser and require choosing a winner and confirming the decision.

“Results” opens directly on a standings list showing place, participant, tournament points and matches played. Tab moves to the phase selector. Completed game results are recorded automatically; you do not need to copy them from the game history.

If the game supports saving, the table host can use Ctrl+S. Resume it from “Saved games”; the continuation still belongs to the same tournament match. A player leaving or losing their connection does not itself produce a draw or forfeit. An unfinished match remains to be completed or settled by the organiser.

### Creating a tournament

Press Ctrl+N on the tournament list. Choose the game, then its variant and ordinary table settings. Confirm these to reach the tournament form. Use Tab to move between fields, arrow keys to change list selections and Space to toggle checkboxes.

- Tournament name — the name other players will see.
- Format — “Round robin” or “Groups and knockout”, explained below.
- Participant limit — the maximum number of registered people, initially 16 and no more than 128. This counts people, not teams, even in pair tournaments. You do not have to fill every place before starting.
- Players per match — the number at one table, not in the whole tournament. This choice appears when the game supports more than one match size.
- Return matches — an extra fixture with the same players and a different seat order. This setting applies to round robin and group matches; knockout rounds and the final have separate settings.
- Game settings — return to the variant and rules that will apply to matches.
- “Dates and playing hours” — optional registration dates, start time and permitted playing periods.

Additional fields depend on the game and format. Return matches are off by default. Publish the tournament when you are ready; filling in the form alone does not make it public.

Publishing also registers you as a participant. If you only want to organise, withdraw before the start. You will still be the organiser.

### Round robin

In two-player matches, everyone plays every opponent. Four players produce six matches, or twelve with return matches. In a fixed-pair tournament, the pairs compete in place of individual players. The player or pair at the top of the final standings wins.

For larger tables, you can choose how the line-ups are arranged:

- “All possible compositions” — every combination of the chosen size gets a match. Four participants playing three at a time produce four different line-ups.
- “Rotating compositions; equal appearances” — players take part in changing line-ups, with everyone playing equally often, without requiring every possible combination.

All combinations can produce a great many games in a large tournament. If the plan exceeds the match limit, reduce the participant count, turn off return matches or choose rotating compositions.

### Groups and knockout

This format supports one-against-one matches and matches between two fixed pairs. You earn points in a group first. After qualifying for the knockout stage, you must beat successive opponents to stay in the competition.

#### Group stage

The program divides participants into groups as evenly as possible, usually three or four players or pairs each. Four participants form two groups of two. You play everyone in your group, including return matches if the organiser enabled them.

The number qualifying depends on the entry count and is chosen to fit a knockout bracket. The group stage does not always eliminate anyone: with eight participants, everyone advances and group places determine the knockout opponents. With nine, there are three groups of three; the group winners and the best runner-up advance.

When comparing candidates for extra qualifying places across unequal groups, results against the last-placed participant in the larger group are left out of that comparison. This gives the candidates the same number of matches. If a tie still prevents qualification or knockout pairings from being decided, the program prepares additional tie-break matches.

#### Knockout rounds and the final

A higher group placing is paired with a lower one, preferably from another group. With two groups of four, for example, the pairings are:

- first in group A against fourth in group B;
- second in group A against third in group B;
- third in group A against second in group B;
- fourth in group A against first in group B.

These are four different pairings, not repeats of the same matches. Winners advance along the bracket and losers are eliminated. The next round is prepared once all matches in the previous round are decided. With only two players or two pairs, the tournament goes straight to a final.

The organiser chooses a match format for the knockout rounds and, separately, for the final:

- “No” return match — a single game decides who advances. A draw requires another game.
- “Yes” — two games with a different seat order. Tournament points from both games are added together. If tied, the program compares the games' own scores where available; if that still does not decide a winner, an extra match is played.
- “Play until a specified number of wins” — keep playing until one side reaches the chosen number of victories, such as two. This does not mean two games: at 1–1, a third is needed, and draws do not count as wins.

### Points and ties

Tournament points are separate from the game's own score. Each match earns you:

- 2 points for each opponent you finish ahead of;
- 1 point for each opponent you tie with;
- 0 points for each opponent who finishes ahead of you.

A two-player match still awards 2–0 for a win or 1–1 for a draw. With no ties, three players receive 4–2–0 and four receive 6–4–2–0. If two players share first place in a three-player match, they receive 3 points each and the third receives 0. If all three tie, each receives 2 points.

A team counts as one participant. A match between two teams therefore awards 2–0 or 1–1, regardless of team size. Team members do not receive separate allocations of points.

Match placings follow the game's outcome and scores. If the game does not provide enough information to rank the remaining participants, they share the place below the winner. In round robin and groups, a return fixture earns its own points.

When tournament points are equal, the program compares results between the tied participants, then the difference between scores for and against, then scores for. It accounts for games where a lower score is better. An incomplete head-to-head comparison is skipped, and missing scores are not treated as zero. If the available criteria cannot break the tie, participants share a place; where qualification needs a decision, extra matches settle it. Shared places leave the following numbers unused: two participants tied for first are followed by third place, not second.

### Dates and playing hours

Open “Dates and playing hours” in the tournament form. You do not have to schedule anything: registration can open immediately, with you closing it and starting the tournament later.

- Registration opening — immediately after publication, at a chosen time, or only when you open it yourself.
- Registration closing — an optional time after which no one else can sign up. Closing registration does not itself start the tournament.
- Tournament start — an optional scheduled start. Starting also closes registration.
- Final deadline — tells participants when they should have played their matches. It does not settle outstanding matches or award forfeits.
- Playing hours — enable the restriction and add periods in which matches can be arranged. Each has a start and end date and time. You can edit or remove saved periods.

Tab to a date field to set it. Left and Right select the year, month, day, hour or minute; Up and Down change that part's value. Times are shown in your computer's local time zone.

Confirm the dates to return to the tournament form, then publish or save your changes to apply them. Scheduled dates can be combined with manual control: for example, open registration immediately and schedule only the start. The tournament finishes when its required matches are decided, not simply when the final deadline arrives.

### Organiser controls

Open your tournament and choose “Manage tournament”. Before the start, you can:

- edit the name, competition settings and dates;
- use “Manage participants” to remove someone or assign partners in a pair tournament;
- open or close registration;
- choose “Start tournament” instead of waiting for a scheduled start.

During the tournament, award forfeits from “Matches”. Select a fixture, open its context menu and choose “Award forfeit”, then select the winner and confirm. A separate option cancels an already-started, unresolved tournament match and awards a forfeit. The chosen winner places ahead of everyone else, and the others share last place. The usual points formula applies; no score is invented for the game itself.

You can also cancel an unfinished tournament. Use this to call off the whole competition, not a single invitation. Missing a deadline or a player's absence does not automatically award a forfeit: that remains the organiser's decision.

### When a change is not confirmed

Tournaments need server access. If registration, publication or another action is not confirmed, do not immediately assume it failed. Refresh the view first.

On the tournament list, open the context menu and choose “Check pending changes”. Select an action with the arrow keys, press Enter for its details and use the check button to find out whether it was accepted. This checks the existing action rather than sending it again. Once the outcome is known, return to the tournament and check its current state before trying again.

## Helping improve the program

### Reporting bugs and suggestions

You can send feedback in the program's ELTEN group or through [GitHub issues](https://github.com/papierek1997/elten-game-room/issues). For a bug report, the most useful details are:

- the Power Games version and build number, and the ELTEN version;
- the game and selected variant;
- a short description of what you did, what happened and what you expected;
- whether the participants were people, bots or spectators;
- the relevant log excerpt if an exception or connection error occurred.

Remove private information from logs before posting them.

### Reporting Quiz questions

In Quiz and Duck Racing questions, Ctrl+B marks the current question and Ctrl+Shift+B marks the previous one. Neither shortcut opens a form, so you can keep playing. After leaving the table, choose Yes when asked whether you want to send reports, describe each problem and press Send. The form also shows the correct answer according to the set. The question and its answers are included automatically. Choosing No discards the marks; reports are not saved as drafts.

### Your own question sets

Open “Create your own quiz question sets” in the main window to see your sets. Press Ctrl+N to create a new set or prepare questions for an existing one. For your own set, enter the title, language and an optional description, then choose “Save”. To add questions to an existing set, choose the language first, press Enter, then choose a set in that language in the next window.

Press Enter on a set to open its menu:

- “Add a question”: enter the question, the correct answer in the first field (A), and three wrong answers in B, C and D. Choose a category from the list. The source and editorial note are optional.
- “Browse questions”: open the list of saved questions. Press Enter to edit the selected question or Ctrl+N to add one.
- “Add a category”: name a category to use in your questions.
- “Delete draft”: remove the whole set after confirmation.
- “Send to the author”: submit the whole set to papierek.

Create at least one category before adding the first question. To add another while writing a question, select “Add a new category” at the end of the category list and press Enter. Your question stays in the form, and the new category is selected automatically.

“Save” keeps your work as a draft. You can return to it later, including on another computer using the same account. Unfinished questions can be saved too. The context menu lets you remove a question or set, or edit a new set's details. On the set list, Delete removes the selected draft after confirmation.

A damaged draft is marked in the list without blocking your other sets. If you no longer want to keep it, press Delete to remove it.

When your questions are ready, choose “Send to the author”. If anything is missing, the creator lists the question numbers and fields to complete. The author reviews your questions before they can be added to the game. After a successful send, the draft leaves your list; if sending fails, you can return to it and try again.
